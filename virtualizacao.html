Sessão 🖥️ Virtualização
Ferramentas para executar máquinas virtuais no Debian. QEMU/KVM é a stack nativa (mais performática) e o GNOME Boxes simplifica a experiência para iniciantes.
🖥️ Máquinas Virtuais

QEMU/KVM + virt-manager

Stack de virtualização nativa do Linux. Roda máquinas virtuais com aceleração por hardware via KVM — é a opção mais performática. Instala o QEMU, o daemon libvirt, o virt-manager (interface gráfica) e configura a rede padrão.

ℹ️ Sobre permissões: seu usuário é adicionado ao grupo libvirt para gerenciar VMs sem precisar de senha em cada ação. O grupo só entra em vigor após logout/login — até lá, o virt-manager vai pedir a senha de administrador ao abrir.
ℹ️ Sobre a rede padrão: no Debian, a rede virtual padrão do libvirt precisa ser iniciada e marcada para autostart (no Fedora isso é automático). O DAP faz isso por você.

GNOME Boxes

Interface gráfica simplificada para criar e gerenciar máquinas virtuais. Usa QEMU/KVM por baixo, então é performático como o virt-manager — a diferença está na experiência: em vez de configurar CPU, RAM e disco separadamente, você aponta para um arquivo .iso e ele cuida do resto.

ℹ️ Recomendado para: quem está começando com virtualização e quer testar uma distribuição Linux ou o Windows sem configurar nada manualmente. Se você já tem experiência, prefira o virt-manager — oferece mais controle sobre a VM.
